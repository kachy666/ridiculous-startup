# ridiculous-startup

One sentence pitching a startup so strange it sounds like a joke — until the money shows up: wedding-speech insurance. If the best man's toast bombs, a professional comic parachutes in mid-toast, and the groom pays $199 to never watch a room go silent. The joke is the product; the fear of a silent reception is the market.

> We insure wedding speeches: if your best man bombs, a professional comic parachutes in mid-toast, because grooms pay $199 to never watch a room go silent.

The program in `main.py` checks the line against the competition rules (one sentence, 1–200 characters, ending with a period) and writes it to `/output/entry.txt`.
